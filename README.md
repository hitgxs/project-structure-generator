# 📁 Estrutura de Projetos

Uma ferramenta simples em Python para visualizar a estrutura completa de pastas e arquivos de qualquer projeto.

## ✨ Funcionalidades

- 🔍 Visualização hierárquica de diretórios
- 🎨 Interface com ícones (📁 para pastas, 📄 para arquivos)
- 🚀 Ignora automaticamente pastas comuns (node_modules, .git, etc.)
- 💾 Opção para salvar a estrutura em arquivo .txt
- 📂 Suporte a caminhos absolutos e relativos

## 🚀 Como Usar

### Instalação

```bash
# Clone o repositório
git clone https://github.com/seu-usuario/estrutura-projeto.git

# Entre na pasta
cd estrutura-projeto

# Execute structure.py
python structure.py

# Escreva o caminho do seu projeto
C:\...\...\...

# Escolha se quer salvar o arquivo em txt
Sim ou Não

# Escolha o nome do arquivo que irá gerar, caso tenha escolhido "sim" (caso não tenha nome em mente, apenas perte "enter")
